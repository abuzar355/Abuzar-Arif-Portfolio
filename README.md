# Abuzar Arif — Portfolio

Static, responsive portfolio website. Open `index.html` locally or deploy this folder to Vercel, Netlify, or GitHub Pages (publish directory: `/`, homepage: `index.html`).

Includes genuine screenshots supplied for the portfolio, project summaries, technology filters, experience, marketplace review excerpts and professional profile links. Private client code is not published.

Please verify each project summary and external link before sharing with prospective clients.

The site includes locally stored review screenshots and portfolio images. The developer workspace hero image is sourced from Unsplash (Blake Connally) and is stored locally for reliable hosting.

GitHub Pages: enable Settings → Pages → Deploy from branch → `main` / `/ (root)`.
